# マークシート採点アプリ

テストの解答用紙(マークシート)を印刷し、複合機でまとめてスキャンした PDF を読み込んで、自動で採点するアプリです。
記述式の問題は、答えの画像を見ながら手で点数を入れられます。生徒に配る個人票や、成績一覧・分析も印刷できます。

## 使い方

校務共有サーバーにある `index.html` を、**Chrome または Edge** で開きます。
初めての方は、画面右上の「はじめての方へ」から、画面の案内とサンプルでの練習ができます。

画面は上から順に4つの手順になっています。

1. **正答と配点** … テスト名・問題数・選択肢の数・正答・配点・記述の欄を入力します。
   - **テスト問題メーカー**で作ったテストなら、テスト問題メーカーの「採点用JSON」で保存したファイルを「正答と配点」の上の枠にドラッグする(または「テスト問題メーカーの正答を読み込む」で選ぶ)だけで、学年・テスト名(問題用紙の題名)・用紙に載せる文(問題用紙の注意書き)・正答・配点・正答の文言・記述欄が入ります。テスト問題メーカーで観点を付けていれば、観点も入ります。このアプリで入れるのは、ふつうは名簿だけです。問題を直して同じテストを読み込み直すと、読み取り結果はそのままで採点し直されます。
   - **模範解答を印刷**:正答・正答の文言・観点・配点と、記述式の模範解答を1枚に印刷します。読み取りや採点が終わっていなくても使えます(テストのすぐあとに答え合わせ用に配る・掲示するなど)。「結果の確認と出力」の画面にも同じボタンがあります。
2. **解答用紙の印刷** … 「解答用紙を印刷」で用紙を印刷し、生徒に配ります。見出しには、テスト名に「解答用紙」が入っていなければ後ろに「解答用紙」を付けます。
   - 個人票・模範解答・成績一覧を印刷するとき、ブラウザが紙の上下に入れる日付・ファイルの場所などは出ません(v1.36 から)。
   - 印刷の画面で送信先を「PDFに保存」にすると、ファイル名は見出しと同じ(例:`1学期期末テスト 理科　解答用紙.pdf`)になります。個人票・模範解答・成績一覧・分析も、それぞれの見出しがファイル名になります。
3. **読み取り** … 回収した用紙を複合機でスキャンして PDF にし、その PDF を読み込みます。
   - **クラスごとの PDF(1組.pdf・2組.pdf…)は、まとめて選べます**(Ctrl を押しながらクリック)。1クラスずつ続けて入れても、結果に追加されます。読み込んだファイルと枚数は画面の下に出ます。
   - 黄色の「要確認」が出たところは、画像を見て正しい答えを選び直してください。
   - 名簿を読み込んでいて、組・番号が名簿に無い用紙は、氏名の欄が黄色で「名簿にない番号」と出ます。用紙の組・番号のマークか、名簿を確かめてください。
   - 「名簿を見る」では、名簿にいるのに読み取った用紙が無い生徒(欠席など)の行が黄色になり、上に人数が出ます。
   - 記述式は「記述を採点する」で、1問ずつ画像を見て点数を入れます。
4. **結果の確認と出力** … 採点結果を確かめて、出力します。
   - **よく使う出力**:「個人票を印刷」(生徒に配る)・「成績一覧・分析を印刷」(得点分布・設問ごとの正答率・組・番号順と順位順の名簿)・「全データをExcelで出力」(全員と組ごとのシート)の3つを大きく並べています。
   - **そのほかの出力**:開くと「観点別の一覧をExcelで出力(評定用)」「CSVで出力」「模範解答を印刷」が出ます。
   - **1人ずつの確認**:表の行を押すと、用紙の画像と解答が画面いっぱいに開きます。「前の生徒」「次の生徒」のボタン(または ← → キー)で順に見られ、その場で解答を選び直せます。解答の横に ○× と正答が出ます。画像を押すと大きくなります。
   - 結果の表が横に長いときは、表の上にも横のスクロールバーが出ます(下まで行かなくても左右に動かせます)。
   - **読み取りの感度**:この画面にもあります。動かすと、要確認の人数・平均点・結果の一覧がすぐ変わります。
   - **出題ミスの疑いの知らせ**:10人以上読み取ると、得点の高い生徒ほどまちがえている問題や、1つの誤答に答えが集まっている問題を、結果の画面と「成績一覧・分析」に出します。正答と問題文を確かめてください(問題がないこともあります)。
   - **全データの Excel**:1つのファイルに、学年全員の「全員」シートと、「1組」「2組」…の組ごとのシートが入ります。各シートの下に正答・配点・正答率の行があり、組ごとのシートの正答率はその組だけで計算します。組は用紙にマークされた組の番号で分けます(組が読めなかった用紙は「組が不明」のシートに入ります)。
   - **個人票に載せる項目**:ボタンの下のチェックで、平均点・組の平均点・最高点・観点ごとの平均点・問題ごとの正答率・得点分布(棒グラフ。自分の位置に★。人数の数字は出しません)・順位・偏差値を、載せるか選べます。はじめは平均点だけです。
   - **観点別の一覧(評定用)**:組・番号・氏名・観点ごとの点数・合計点だけの Excel ファイルができます。組が2つ以上あれば、組ごとのシートも付きます。名簿を読み込んでいれば名簿の全員が組・番号順に並び、用紙がない人(欠席など)は空欄の行になるので、評定の表に行をそろえて貼り付けられます。

生徒の氏名を出したいときは、「名簿(氏名)を読み込む」で組・番号・氏名の CSV を読み込みます。フリガナの列があれば、個人票の氏名の上にフリガナが出ます(無くてもかまいません)。

- 1行目に「学年」「組」「番号」「氏名」「フリガナ」などの見出しがあれば、列の順はどうでもかまいません(「姓」「名」に分かれていてもよい)。見出しが無いときは「組・番号・氏名・フリガナ」の順、または「学年・組・番号・氏名・フリガナ」の順にします。「1組」「5番」のように単位が付いていても読めます。
- 読み込むと、画面に **「名簿を見る」** が出て、名簿の一覧(読み取った用紙があるか)と、名簿にない組・番号の用紙を確かめられます。名簿にない用紙があるときは、組・番号のマークの読み取りか、名簿の組・番号を確かめてください。

マークは **HB以上の鉛筆かシャープペンシル** で濃く塗るよう、生徒に伝えてください(解答用紙にも印刷されています)。

## データの保存場所

- はじめに **「保存するフォルダ」** を選びます(v1.27 から)。**校務共有サーバー**(このアプリと同じフォルダなど)か、このパソコンのフォルダにします。共有サーバーにすれば、別のパソコン・別のブラウザで開いても同じデータを使えます。
- **生徒の解答と名簿が入るので、インターネットやクラウド(Google ドライブなど)から見えるフォルダは選ばないでください。**
- 入力した正答・配点・読み取り結果・名簿は、そのフォルダの中の **データファイル**(`マークシート採点_データ_2年_テスト名.json`)に自動で保存されます。**1つの学年の1つのテストに1つのファイル**です(名簿はテストごとに変わることがあるため)。テスト名に学年が入っていなければ、ファイル名の前に「2年_」のように付けます。
- 画面右上の **「保存・開く」** で、次のことができます。
  - **新規作成**:新しいテストを始めるとき。学年とテスト名を入れると、すぐにファイルができます。そのあとは、手で正答を入れても自動で保存されます。テストを開いているときは、**白紙から始める**か、**今のテストの正答・配点を使う**か(同じテストを別のクラスで使うときなど)と、今の名簿を使うかを選べます(今のテストのファイルはそのまま残ります)。ファイルを作らずに正答を読み込んだときにも、この画面が出ます(今の内容が入ります)。
  - **開く**:前に保存したテストの続きをするとき。フォルダの中のテストの一覧から選びます。
  - **前の日の状態に戻す**:まちがえて消した・直したとき。下の「バックアップ」から、戻したい日を選びます。
- **ファイルを作るまでは、どこにも保存されません。** 画面の上に「まだファイルに保存していません」と出て、タブを閉じようとすると確認が出ます。ブラウザの中にも残しません(共用のパソコンに生徒のデータが残らないように。v1.25 までは、ブラウザの中にも控えを残していました)。
- データファイルを開いたまま、**別のテストの正答を読み込むと**、前のテストのデータファイルには上書きしません。「新規作成してください」という画面が出るので、**「新規作成」** を押して、このテスト用のファイルを作ってください。同じテストの正答を読み込み直したとき(問題を直したときなど)は、そのまま同じファイルに保存します。
- アプリを開くと、はじめに **「開く」「新規作成」「閉じる」** を選ぶ画面が出ます(v1.29 から。前回のテストを黙って開くと、別のテストのつもりで入力してしまうことがあるため)。続きをするときは「開く」で、一覧から前回のテスト(「(前回)」と付いています)を選びます。ブラウザが「このフォルダのファイルの表示と編集を許可しますか」のようにたずねたら、**「ファイルを編集」(または「許可」)** を押してください。
- 別の画面や別のパソコンで同じデータファイルが書き換えられたときは、上書きせずに自動保存を止め、画面の上に知らせます。「変更を読み込む」か「この画面の内容で上書き」を選んでください。
- ファイルへの直接保存は **Chrome か Edge** でだけ使えます。
- **読み取った用紙の画像**は、そのフォルダの中の **`画像`** フォルダに、テストごとのフォルダを作って1枚ずつ保存します(v1.33 から。例:`画像\マークシート採点_データ_2年_テスト名\`)。1枚およそ 200〜300KB で、160人なら1つのテストで 40MB くらいです。テストを開き直しても、用紙の確認・記述の採点・個人票の記述の答えに画像が使えます。用紙を削除したり、読み取り結果をすべて消したりすると、その画像も消えます。画像はデータファイルには入りません(大きいため)。
- 1.32 までに読み取った用紙の画像は残っていません。必要なら元の PDF を読み取り直してください。元の PDF も校内の決められた場所に保管してください。
- 1.26 までに作ったデータファイルも、同じフォルダに入れておけば「開く」の一覧に出ます。1.25 までの版で、ファイルに保存せずブラウザの中にだけ残っていた内容があれば、はじめに開いたとき「ファイルに保存してください」の画面が出ます。「新規作成」でファイルに保存してください。

## バックアップ(自動)

- データファイルに保存するたびに、同じフォルダの中の **`バックアップ`** フォルダに、その日の状態を自動で残します(`マークシート採点_データ_2年_テスト名_2026-11-06.json`)。**1日1つ**で、その日の最後の状態です(10分おきに書き直します)。
- **30日** より古いバックアップは自動で消します(日数は、ファイルの先頭の設定 `BACKUP_KEEP_DAYS` で変えられます)。
- 戻すときは、「保存・開く」→ **「前の日の状態に戻す」** で日付を選びます。戻す前の内容も「戻す前」として `バックアップ` フォルダに残すので、戻しすぎても元に戻せます。
- 「新規作成」で同じ名前のファイルに上書きしたとき、「前のファイルに上書き」を選んだとき、保存していない内容があるまま別のテストを開いたときも、前の内容を「上書き前」「開く前」として残します。
- 手で保存するバックアップのボタンは、v1.27 でやめました(紛らわしいため)。1.26 までに「バックアップを保存」で書き出したファイル(`マークシート採点_バックアップ_日付_テスト名.json`)は、「前の日の状態に戻す」→「前の版のバックアップを選ぶ」で戻せます。
- 用紙の画像はバックアップに入りません。前の日の状態に戻したとき、そのあとで削除した用紙の画像は戻りません(点数や解答は戻ります)。

## 困ったとき

| こんなとき | どうする |
|---|---|
| PDF を読み込めない | 複合機で保存し直した PDF で試してください。うまくいかないときは、JPG・PNG の画像でスキャンしても読めます。 |
| 「要確認」が多すぎる・少なすぎる | 「読み取りの感度」を調整してください。 |
| 読み取り結果がおかしい | 「使い方・引き継ぎ」→「自己診断を実行」で、アプリが正しく動いているか確かめられます。 |
| 前のテストのデータが消えた | 「保存・開く」→「開く」で、そのテストのデータファイルを選んでください。無いときは、そのテストを開いて「保存・開く」→「前の日の状態に戻す」で戻してください。 |
| 画面の上に「まだファイルに保存していません」と出る | 入力した内容が、まだどこにも保存されていません。「新規作成」で新しいファイルに保存するか、続きのテストなら「開く」でそのファイルを選んでください。ブラウザの問いには「ファイルを編集」(または「許可」)を選びます。 |
| 画面の上に「ほかの画面かパソコンで…変更されました」と出る | ほかの画面で同じテストを開いていないか確かめ、「変更を読み込む」を押してください。この画面の内容を残したいときだけ「この画面の内容で上書き」を押します。 |

## 後任の先生・開発者へ

- 仕組み・注意点・次にやることは [HANDOFF.md](HANDOFF.md)、変更の記録は [CHANGELOG.md](CHANGELOG.md) にあります。アプリ内の「使い方・引き継ぎ」にも説明があります。
- 問題数・選択肢の上限や用紙の寸法は、ファイル先頭近くの `LAYOUT` にまとまっています。変えると、すでに印刷した用紙は読めなくなります。
- 使っている外部ライブラリ:pdf.js 3.11.174(PDFの読み込み、Mozilla)。インターネットなしで動くよう、`index.html` の末尾に入れてあります(アプリ本体のコードはその手前までです)。
