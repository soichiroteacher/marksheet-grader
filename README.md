# マークシート採点アプリ

テストの解答用紙(マークシート)を印刷し、複合機でまとめてスキャンした PDF を読み込んで、自動で採点するアプリです。
記述式の問題は、答えの画像を見ながら手で点数を入れられます。生徒に配る個人票や、成績一覧・分析も印刷できます。

## 使い方

校務共有サーバーにある `marksheet-saiten.html` を、**Chrome または Edge** で開きます。
初めての方は、画面右上の「はじめての方へ」から、画面の案内とサンプルでの練習ができます。

画面は上から順に4つの手順になっています。

1. **正答と配点** … テスト名・問題数・選択肢の数・正答・配点・記述の欄を入力します。
2. **解答用紙の印刷** … 「解答用紙を印刷」で用紙を印刷し、生徒に配ります。
3. **読み取り** … 回収した用紙を複合機でスキャンして PDF にし、その PDF を読み込みます。
   - 黄色の「要確認」が出たところは、画像を見て正しい答えを選び直してください。
   - 記述式は「記述を採点する」で、1問ずつ画像を見て点数を入れます。
4. **結果の確認と出力** … 採点結果の確認、「CSVで出力」(Excel で開けます)、「個人票を印刷」「成績一覧・分析を印刷」ができます。

生徒の氏名を出したいときは、「名簿(氏名)を読み込む」で組・番号・氏名の CSV を読み込みます。

## データの保存場所

- 入力した正答や採点結果は、**今使っているパソコンのブラウザの中**(保存領域)に自動で保存されます。共有サーバーやインターネットには送られません。
- スキャンした画像も、このパソコンの中だけで処理します。

## バックアップと復元

- **バックアップ**:画面右上の「バックアップを保存」を押すと、`マークシート採点_バックアップ_日付_テスト名.json` がダウンロードされます。テストごとに、採点が終わったら保存しておいてください。
- **復元**:「バックアップを開く」で、保存したファイルを選びます。
- スキャンした画像はバックアップに入りません(ファイルが大きくなりすぎるため)。バックアップから開いたときは、記述の答えの画像は表示されません。
- 以前のバックアップ(`20260926_テスト名_バックアップ.json` のような名前)も、同じ方法で開けます。

## 困ったとき

| こんなとき | どうする |
|---|---|
| PDF を読み込めない | 複合機で保存し直した PDF で試してください。うまくいかないときは、JPG・PNG の画像でスキャンしても読めます。 |
| 「要確認」が多すぎる・少なすぎる | 「読み取りの感度」を調整してください。 |
| 読み取り結果がおかしい | 「使い方・引き継ぎ」→「自己診断を実行」で、アプリが正しく動いているか確かめられます。 |
| 前のテストのデータが消えた | 「バックアップを開く」で、そのテストのバックアップを開いてください。 |

## 後任の先生・開発者へ

- 仕組み・注意点・次にやることは [HANDOFF.md](HANDOFF.md)、変更の記録は [CHANGELOG.md](CHANGELOG.md) にあります。アプリ内の「使い方・引き継ぎ」にも説明があります。
- 問題数・選択肢の上限や用紙の寸法は、ファイル先頭近くの `LAYOUT` にまとまっています。変えると、すでに印刷した用紙は読めなくなります。
- 使っている外部ライブラリ:pdf.js 3.11.174(PDFの読み込み、Mozilla)。インターネットなしで動くよう、`marksheet-saiten.html` の末尾に入れてあります(アプリ本体のコードはその手前までです)。
